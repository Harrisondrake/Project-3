# CIVE 202 Project 3 – Transportation Data Visualization

## Project Summary
This project was completed for CIVE 202: Civil Engineering Analysis II (Spring 2026) 
in response to a Request for Proposal from the Federal Highway Administration (FHWA). 
The analysis visualizes transportation trends using the National Household Travel Survey 
(NHTS) and Next Generation Simulation (NGSIM) datasets, and includes an Intelligent 
Driver Model (IDM) car-following simulation.

## File Descriptions
| File | Description |
| `project3.ipynb` | Main Jupyter Notebook containing all Python code, visualizations, and IDM simulation |
| `NHTS(in).csv` | National Household Travel Survey dataset (input data) |
| `NGSIM(in).csv` | Next Generation Simulation vehicle trajectory dataset (input data) |
| `annotated_code.xlsx` | Excel document with line-by-line code annotations |
| `scope_of_work.docx` | Scope of work document outlining project goals and tasks |
| `technical_report.docx` | Written technical report summarizing findings |

## How to Run
1. Open `project3.ipynb` in Jupyter Notebook or JupyterLab
2. Ensure `NHTS(in).csv` and `NGSIM(in).csv` are in the same folder as the notebook
3. Run all cells in order from top to bottom

## Libraries Required
- pandas
- numpy
